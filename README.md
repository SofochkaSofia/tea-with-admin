# 🚀 Nuxt 3 Boilerplate

Универсальный шаблон для контентных проектов с блогом и админ-панелью.

## 🛠 Стек технологий

- **Framework:** Nuxt 3 + Vue 3 + TypeScript
- **Database:** PostgreSQL + Prisma ORM
- **Auth:** Яндекс ID, ВКонтакте (OAuth 2.0)
- **i18n:** Мультиязычность (RU, EN, DE, TR)
- **Styling:** Tailwind CSS
- **Images:** @nuxt/image
- **Package Manager:** pnpm

## ⚡ Быстрый старт
